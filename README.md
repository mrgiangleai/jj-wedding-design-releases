# JJ Wedding Design – bản cài

Tải bản mới nhất ở mục [Releases](https://github.com/mrgiangleai/jj-wedding-design-releases/releases/latest).

- macOS: `JJ-Wedding-Design-<phiên bản>.dmg`
- Windows: `JJ-Wedding-Design-<phiên bản>-Setup.exe`

Đã cài rồi thì app tự báo khi có bản mới, bấm **Cập nhật** là xong. Cần key bản quyền để dùng.
